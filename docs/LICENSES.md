# Licenças do acervo

Toda obra ingerida na base precisa de uma ficha aqui antes de ser habilitada (`works.enabled = true`), e precisa passar pela regra da seção 8.10.9 da especificação. Licenças NC, ND ou sem informação não entram.

## Modelo de ficha (seção 14.8)

```
## <work_id> — <Título>
- Autor(es) / tradutor(es) e anos de morte:
- Edição e ano de publicação:
- Licença:
- Crédito exigido (texto exato):
- Fonte (URL):
- Data da coleta:
- Hash SHA-256 do arquivo:
- Observações:
```
